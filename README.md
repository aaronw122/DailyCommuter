# Daily Commuter

A mobile app that shows your daily bus times at a glance. Built because my phone didn't know me — every day I take the same bus to work but had to go through a laborious process to check the same time. I wanted a widget on my home screen. So I built one.

## What it does

- Shows real-time CTA bus arrival times for your saved stops
- Home screen widget for instant access — no app launch needed
- Save favorite routes and stops for one-tap viewing
- iOS native widget built with SwiftUI

## Try it

[Download on TestFlight](https://testflight.apple.com/join/yW1pzgWA)

## Tech stack

- **Frontend:** React Native (Expo) + TypeScript
- **iOS Widget:** SwiftUI with native bridge
- **Data:** CTA Bus Tracker API
